Dhizuku GitOps MDM Console

Serverless Over-The-Air Android Device Owner Control Plane (No USB / WebADB Required)

1. GitHub Repository & Auth Connection

Your GitHub Personal Access Token (PAT) is saved strictly in browser localStorage and used to commit policy.json, config.json, and uploaded apks/*.apk files via the GitHub Contents API.

Ready. Click "Load Live Policy" to fetch the latest manifest from GitHub.

2. System User Restrictions (UserManager)

Enforced via DevicePolicyManager.addUserRestriction() / clearUserRestriction() through Dhizuku's Device Owner binder proxy.

3. App Hiding, Freezing & Remote Uninstall

Freeze/hide apps via setApplicationHidden(admin, pkg, true) or completely uninstall apps over the air via Dhizuku's wrapped PackageInstaller.uninstall().
